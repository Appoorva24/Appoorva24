## Featured Projects

### ReBloom
**Postpartum Wellness Application**

A dual-interface iOS app supporting mothers and partners through the postpartum journey.

**Stack:** SwiftUI, SwiftData, Lottie, AVFoundation

Key Features:
- Dual user interfaces for Mother and Partner roles
- Pelvic floor and breathing exercise flows
- SOS alert system with partner notifications
- Weekly reflections and baby milestones tracker
- Partner acknowledgment and visibility system

---

### Focus4Good
**Productivity System**

Impact-driven workflow tool with structured focus mechanisms and behavioral design.

**Stack:** Swift, SwiftUI, SwiftData, Firebase

Key Features:
- Goal-oriented task management
- Smart scheduling with focus tracking
- Pomodoro timer integration
- Progress analytics and habit tracking
- Customized UI for sustained focus

---

### Swiggy Data Dashboard
**Analytics and Insights**

Data analytics project extracting operational insights using Python and Power BI.

**Stack:** Python, Pandas, NumPy, Power BI

Key Features:
- Interactive data visualizations
- Pattern recognition and trend analysis
- Business intelligence dashboards
- Operational metrics tracking
